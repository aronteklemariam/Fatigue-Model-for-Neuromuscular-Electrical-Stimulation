README — Axon Action Potentials and Muscle Activation Simulation
================================================================

FILES
-----
1. run_axon_output.m — Generates action potentials using the axon model.
2. Tetani_Hans.mat — Generated by the first script; contains the variable EndPlate.
3. run_model.m — Loads EndPlate and simulates muscle activation and fatigue.

Keep the MATLAB scripts and required supporting functions on the MATLAB path. The scripts call functions including fv1, fv, fm, fn, fh, and nmj2, which are not included in these two files. MATLAB functions findpeaks, square, and resample are also used.

STEP 1 — GENERATE ACTION POTENTIALS
-----------------------------------
Open run_axon_output.m and adjust these three settings consistently:

    stop = 1500;         % Total ON + OFF cycle duration (ms)
    t = 0:dt:1500;       % Time vector spanning the complete cycle (ms)
    t1 = 0:dt:500;       % Stimulation ON interval (ms)

Example: 500 ms ON and 1000 ms OFF:
    stop = 1500;
    t = 0:dt:1500;
    t1 = 0:dt:500;

Here, t1 controls the ON fraction of the overall ON–OFF cycle (500/1500 = 33.3%). This is different from the duty cycle of individual electrical pulses, which is set separately by the square(...) expression. In the supplied code the square-wave frequency is 75 Hz and its duty argument is 3.01%.

Run run_axon_output.m. At the end it executes:
    EndPlate = V(7,:);
    save('Tetani_Hans', 'EndPlate');

This creates Tetani_Hans.mat in MATLAB's current working folder. The file stores the EndPlate signal for the subsequent muscle simulation.

STEP 2 — SIMULATE MUSCLE ACTIVATION
-----------------------------------
Open run_model.m. The script loads the saved signal:
    str = "Tetani_Hans.mat";
    load(str);

Set the desired simulation duration:
    minutes = 3;

Then modify the repetition calculation to match the complete stimulation cycle:
    iteration = round(1500/((length(EndPlate)*0.001)));
    iteration = iteration*40*minutes;

Meaning of the values:
- 1500: complete stimulation ON + OFF cycle duration, in milliseconds.
- length(EndPlate)*0.001: approximate duration (ms) of one stored signal, given the axon simulation's 0.001 ms time step.
- 40: complete ON–OFF cycles per minute; 60000/1500 = 40.
- minutes: requested overall simulation duration, in minutes.

For a different cycle duration, update BOTH 1500 and 40:

    Cycle duration       Cycles per minute
    1000 ms              60
    1500 ms              40
    2000 ms              30
    5000 ms              12

General relationship:
    cycles_per_minute = 60000 / cycle_duration_ms;

For clarity, the calculation can be expressed as:
    cycle_duration_ms = 1500;
    cycles_per_minute = 60000 / cycle_duration_ms;
    iteration = round(cycle_duration_ms / (length(EndPlate)*0.001));
    iteration = iteration * cycles_per_minute * minutes;

This preserves the intended calculation, although the exact number of repetitions may be affected by rounding and the loop boundary.

Run run_model.m after generating Tetani_Hans.mat. The code calculates calcium-related dynamics, muscle force, phosphate accumulation, ATP and changes in SR calcium release. Its final figure plots force (%), phosphate concentration [Pi] (mM), and the K3 calcium-release parameter against time (minutes).

NOTES / CHECKS
--------------
- Always regenerate Tetani_Hans.mat when changing the stimulation cycle in run_axon_output.m.
- Ensure the generated .mat file is accessible from MATLAB's current folder or path.
- The loop in run_model.m uses 'while counter2 < iteration', so the executed count is one less than iteration for an integer iteration >= 1. Verify the simulated duration if exact timing is required.
- The plotting limits in run_model.m are hard-coded (time axis up to 2.05 min), despite 'minutes = 3'. Adjust axis limits for other durations.
- The initial 500 zeros in the plotted output and the fixed time shift of 0.0998 min are part of the supplied plotting code; review these if precise timing is important.
